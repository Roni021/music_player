# Audio

Drop MP3 files here named to match `audioSrc` in `data/music.ts`:

```
song-1.mp3 … song-8.mp3
```

When a file is missing, Midnight Melodies synthesises the track in the browser from the
`f1` and `f2` frequencies on each song, so the player always works out of the box. No
copyrighted audio ships with this project.
